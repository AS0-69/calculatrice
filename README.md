# 🧮 Calculatrice - Application Java

Une calculatrice fonctionnelle développée en **Java** avec interface graphique Swing. Effectuez toutes vos opérations mathématiques de base avec une interface intuitive et professionnelle.

## 📋 Fonctionnalités

- ➕ **Addition** - Additionner deux nombres
- ➖ **Soustraction** - Soustraire deux nombres
- ✖️ **Multiplication** - Multiplier deux nombres
- ➗ **Division** - Diviser deux nombres (avec gestion de la division par zéro)
- 🔢 **Décimales** - Support des nombres décimaux
- 🔄 **Clear (C)** - Réinitialiser les calculs
- ⌫ **Delete** - Supprimer le dernier caractère
- 🎨 **Interface graphique** - Design moderne et responsive

## 🛠️ Technologies Utilisées

- **Java** - Langage de programmation
- **Swing** - Interface graphique utilisateur (GUI)
- **AWT** - Gestion des événements

## 🚀 Installation et Exécution

### Prérequis
- Java JDK 8 ou supérieur installé sur votre machine

### Compilation et exécution

```bash
# Clonez le repository
git clone https://github.com/AS0-69/calculatrice.git

# Accédez au dossier
cd calculatrice

# Compilez le programme
javac Calculatrice.java

# Exécutez l'application
java Calculatrice
```

## 💻 Utilisation

1. Lancez l'application
2. Cliquez sur les boutons numériques pour entrer des nombres
3. Sélectionnez une opération (+, -, ×, ÷)
4. Entrez le deuxième nombre
5. Appuyez sur **=** pour obtenir le résultat
6. Utilisez **C** pour effacer ou **DEL** pour supprimer le dernier caractère

## 🎯 Caractéristiques Techniques

- Architecture orientée objet
- Gestion des événements avec ActionListener
- Interface utilisateur responsive
- Validation des entrées
- Gestion des erreurs (division par zéro, etc.)

## 📸 Interface

L'application présente :
- Un écran d'affichage des calculs
- Boutons numériques (0-9)
- Boutons d'opérations (+, -, ×, ÷)
- Bouton égal (=)
- Boutons de contrôle (C, DEL)
- Support du point décimal (.)
